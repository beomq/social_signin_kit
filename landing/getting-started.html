Get started / two steps

Add the package. Attach your events.

The widget owns the button UI. Your app owns what happens after a press: OAuth, loading, errors, tokens, and navigation.

All 35 providers include package PNG defaults: six are reviewed provider-supplied originals, and the other 29 are package adaptations rendered from pinned Simple Icons SVGs. No consuming-app asset setup is required for the defaults.

01 / pubspec.yaml

Add the local dependency.

This checkout is not published to pub.dev. Point the consuming app at the package location you actually use.

YAML / dependency 
dependencies:
  social_signin_kit:
    path: ../social_signin_kit

02 / event handlers

Pass the events your app already owns.

Each SocialButton receives its own onPressed. Passing null disables that button while your app is busy.

A press starts your handler; it does not prove that sign-in succeeded. Keep request state and authentication results in the app.

All 35 providers have package PNG defaults, so this quick start needs no consuming-app logo paths. Six are reviewed provider-supplied originals; the other 29 are package adaptations rendered from pinned Simple Icons SVGs.

Dart / attach events 
import 'package:social_signin_kit/social_signin_kit.dart';

SocialButtonList.vertical(
  items: [
    SocialButton(
      social: Social.google,
      onPressed: isSigningIn ? null : startGoogleSignIn,
    ),
    SocialButton(
      social: Social.kakao,
      onPressed: isSigningIn ? null : startKakaoSignIn,
    ),
    SocialButton(
      social: Social.naver,
      onPressed: isSigningIn ? null : startNaverSignIn,
    ),
  ],
)
